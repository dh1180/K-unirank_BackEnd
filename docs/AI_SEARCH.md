# AI 입결 검색: 근거 조회와 대화 조건

- 첫 질문에 내신이 없어도 수시 9등급제 교과/종합의 공개 50/70 컷을 조회한다. grade/gap은 null이며 비교 차트는 만들지 않는다.
- 다음 질문에는 React 메모리의 직전 구조화 조건만 전송한다. 원문 대화나 개인정보를 DB/localStorage에 저장하지 않는다. 새 질문/새로 검색으로 초기화한다.
- 명시된 변경 조건이 이전 조건보다 우선한다. 전체 지역/전체 학과/등급 없이/최신 등 초기화 표현을 지원한다. 클라이언트와 서버에서 필드·길이·열거형·범위를 검증한다.
- 이미 아는 별칭과 후속 조건은 규칙으로 처리해 OpenRouter 지연·요금에 의존하지 않는다. 미등록 자연어 학과의 첫 등급 질문에만 기존 무료 모델을 이용한다.
- 대학 비교는 최대 4개, 같은 학년도·전형·지역·학과 검색 조건으로 표시한다. 공시 지표는 각 항목의 공시 연도와 단위를 표시한다. 환산점수로 우열/합격확률을 산출하지 않는다.
- 기존 이상치 제외·특별전형 기본 제외·공식 출처 우선 중복 제거 기준을 재사용한다. 요청 연도가 없으면 최신 연도, 요청 연도에 자료가 없으면 빈 결과를 반환한다.
- 모집요강은 아래 등록된 공식 PDF만 검색한다. 같은 대학/학년도에서 키워드가 있는 페이지를 최대 3개 찾아 문맥을 발췌한다. 페이지 번호는 표지 포함 PDF 물리 페이지이며 원문 URL에 #page를 붙인다. 지원자격 충족/미충족 여부는 추론하지 않는다. 다른 대학/연도로 대체하지 않는다.

## 모집요강 운영

현재 한국항공대 2027 수시, 가천대 2026/2027 수시 PDF 3건. 전국 모집요강이 확보된 서비스로 표현하지 않는다.

1. 입학처에서 현재 공고된 PDF 제목, 학년도, 수정일을 확인한다.
2. scripts/ai-guide-manifest.json에 문서 메타데이터를 추가한다. 새 공식 호스트는 index_ai_guides.py의 운영자 허용 목록에 추가한다.
3. pypdf(Windows는 필요시 truststore) 설치 후 python scripts/index_ai_guides.py 실행.
4. 추출한 본문과 실제 PDF 페이지를 대조하고 SHA-256/페이지 수/학년도, URL이 올바른지 확인한다.
5. 색인 JSON과 문서 목록/화면의 지원 범위를 함께 갱신하고 테스트/배포한다.

운영 서버는 PDF를 다운로드하거나 Python/벡터 DB/추가 FastAPI를 실행하지 않는다. 약 0.5MB의 정적 색인을 Spring 시작 시 읽는다. DB 스키마 변경은 없다. 로그인·출처 검증·분당 제한·비공개 토큰 및 기존 무료 모델 예산은 유지한다.
